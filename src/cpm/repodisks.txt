WHAT IS ON THE DISKS
====================

What is on each disk image the gateway is known to run, so you can
tell which one you want before going to find it.  These are not
shipped with the gateway -- they are other people's collections, and
the readme in this folder says how to put one here.

Every disk is listed once, by name, A to Z, whichever collection it
came from -- the index below, then the same disks in full.  Eight
names exist in more than one collection and are different disks, so
each entry names the collection it came from.

Each listing is the disk's OWN directory, read through the same
mount path the gateway uses, and the line under each name is worked
out from those files -- not from the filename and not from anyone's
catalogue.  A disk with no CP/M filesystem says so instead: it boots
its own operating system, and where it keeps its files is that
system's business.

      https://github.com/jpmcneely/AltairDuino-Disks  (the original/ folder)
